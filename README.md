# 항도제일특수브러쉬 — AI 제작상담 MVP

> 2026학년도 2학기 기술개발연구프로젝트 · 중간 MVP (개인 과제)
> 실제 회사(항도제일특수브러쉬) 홈페이지 리뉴얼의 1단계 결과물입니다.

> ✍️ 표시가 있는 문단은 **본인(김시은)이 직접 다시 써야 하는 부분**입니다. 제출 전 지우고 본인의 말로 채웁니다.

---

## 1. 목적

산업용 브러쉬를 주문하려는 기업 담당자가 **브러쉬 이름·소재·규격을 몰라도** 몇 가지 질문에 답하면 제작 문의에 필요한 정보가 정리되도록 돕는 웹 서비스입니다. 정리된 요약을 카카오톡 채널이나 메일로 보내면, 회사 담당자는 기본 정보를 다시 묻지 않고 바로 기술 검토를 시작할 수 있습니다.

✍️ (이 프로젝트를 왜 시작했는지 — 회사 현장에서 직접 본 문제를 1~2문장으로)

## 2. 사용자와 줄이려는 불편

| 구분 | 내용 |
|---|---|
| **사용자 (한 유형)** | 산업용 브러쉬 전문지식이 부족한 **기업 구매담당자** |
| **줄이려는 불편** | 제품명·소재·규격을 몰라 불완전한 제작문의를 남기고, 담당자와 여러 번 연락을 주고받으며 기본 정보를 다시 확인해야 하는 불편 |
| **핵심 흐름** | 홈 → **AI 제작상담** → 4단계 질문(모르면 "잘 모르겠습니다") → 검토 후보 형태·소재 + 확인 필요 규격 → **문의 요약** → 복사 후 카카오톡/메일로 전달 |

범위 밖(이번 MVP에서 하지 않음): 실제 LLM 호출, 문의 저장·자동 전송, 로그인, 실제 주문 데이터, 결제

## 4. 사용법

1. 공개 주소에서 **[AI 제작상담 시작]** 버튼을 누릅니다.
2. **1단계 작업 목적** — 작업 목적과 대상물을 고릅니다 (두 항목만 필수). 맞는 항목이 없으면 "기타"를 고르고 직접 적습니다.
3. **2~3단계** — 사용 방식, 치수, 회전 속도, 환경, 소재를 아는 만큼만 답합니다. 모르면 "잘 모르겠습니다"나 "치수를 모릅니다"를 고르고 넘어갑니다.
4. **4단계** — 수량·납기·사진/도면 여부를 적고 **[결과 보기]** 를 누릅니다.
5. 결과 화면에서 검토 후보 형태·소재, **확인이 필요한 규격**, 기술 검토 필요 사항을 확인합니다.
6. **[요약 복사]** → **[카카오톡으로 상담]** 을 눌러 채팅창에 붙여 넣거나, **[메일로 보내기]** 를 누릅니다.

부가 기능: 주문조회 데모(`/order/`, 데모 번호 `HJ-DEMO-001`~`003`), 회사소개, 제품 사진, 문의 안내

**상태 확인 방법 (검증용)**

| 상태 | 확인 방법 |
|---|---|
| 로딩 | 마지막 단계에서 [결과 보기] → 약 0.6초간 표시 |
| 정상 | 작업 목적 "녹·스케일 제거" + 대상물 "철·스틸" |
| 빈 결과 | 작업 목적 "기타" + 아무 내용 입력 → 일치 규칙 없음 안내 + 요약은 생성 |
| 오류 | 주소 끝에 `?simulate=error` 를 붙여 진행 (예: `/finder/?simulate=error`) |
| 잘못된 입력 | 필수 항목 비우기, 외경에 `abc`, 수량에 `2.5`, 지난 날짜 납기, 주문번호 `INVALID` |

**개인정보·보안**
- 이름·연락처 등 **개인정보를 수집·저장하지 않습니다.** 상담 입력은 브라우저 안에서만 처리되며, 사용자가 직접 복사해 보낼 때만 회사로 전달됩니다. 메모 칸에는 개인정보를 적지 말라고 안내합니다.
- 서버·DB·외부 API를 쓰지 않으므로 **인증키가 없습니다.** 저장소에 비밀값이 없고 `.gitignore` 로 `.env*` 파일 커밋을 막아 두었습니다. 11월 이후 키가 필요해지면 GitHub Secrets / Vercel 환경변수에만 저장합니다.
- 방문 분석 도구, 쿠키, 로그인이 없습니다.

## 7. 알려진 한계

- **추천은 데모 규칙 8개 기반**입니다. 회사 전문가 검토를 받지 않았고, 실제 LLM을 호출하지 않습니다. 화면과 요약에 "기술 검토 전"을 표시합니다.
- 요약은 **자동 전송되지 않습니다.** 사용자가 복사해 카카오톡/메일로 보내야 합니다. 카카오톡 채널은 채팅창에 내용을 미리 채울 수 없습니다.
- 사진·도면 **업로드 기능이 없습니다.** 카카오톡·메일에 직접 첨부하도록 안내합니다.
- 긴 요약은 메일 링크 길이 제한 때문에 일부가 잘리므로 "요약 복사"를 권장합니다.
- 주문조회는 **가상 데이터**입니다. 회사 생산 일정은 아직 종이로 관리됩니다.
- 제품 사진 설명·분류는 외형을 보고 추정한 것으로 회사 확인 전입니다. 공식 로고 파일은 아직 받지 못해 임시 "HJ" 표시를 씁니다.
- 한국어만 지원합니다. SEO는 기본 메타데이터 수준입니다.

## 개발

```bash
npm install
npm run dev            # 개발 서버 http://localhost:3000
npm test               # 단위 테스트
npm run lint           # 타입 검사
npm run build:pages    # GitHub Pages용 빌드 (out/)
npm run preview        # http://localhost:4173/hangdo-brush/
```

구조: `UI(features/*) → services/* → engine(features/finder/engine.ts) + data/*`
추천 규칙은 `src/data/brush-rules.ts` 만 고치면 화면 코드 수정 없이 바뀝니다. 전체 기획은 [docs/MASTER_BRIEF.md](docs/MASTER_BRIEF.md) 참고.
