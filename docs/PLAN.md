## 문제 정의
- 사용자: 산업용 브러쉬 전문지식이 부족한 기업 구매담당자
- 불편: 제품명·소재·규격을 몰라 불완전한 제작문의를 남기고 담당자와 반복 확인
- 핵심 흐름: 홈 → 제작상담 → 4단계 질문 → (로딩) → 검토 후보 + 확인 필요 규격 → 문의 요약 → 복사 / 메일 / 카카오

## 기술 스택
- Next.js (App Router) + TypeScript, `output: 'export'` 정적 빌드, basePath `/hangdo-brush`
  (변경 사유: 11월 Vercel 이전·관리자 앱·SEO용 정적 HTML을 코드 재작성 없이 이어가기 위해)
- 빌드가 막히면 즉시 Vite + React로 되돌린다 (마감 우선)
- 일반 CSS + 디자인 토큰 (deep green), Pretendard (OFL, CDN)
- Vitest (추천 엔진 단위 테스트)
- GitHub Actions → GitHub Pages (push to main, workflow_dispatch)
- 구조: UI → brushFinderService → localBrushEngine (11월: /api/brush-finder 로 교체)

## 범위

- P1: 회사소개 1페이지(인사말·연혁·오시는 길), 제품 사진 갤러리
- P2: 주문조회 데모 (HJ-DEMO-001~003)

## 상태
- 로딩: 결과 계산 중 (서비스 비동기)
- 정상: 후보 있음
- 빈 결과: 일치 규칙 없음 → 담당자 검토 안내 + 요약은 생성
- 오류: 데이터/복사 실패 → 이유와 대안 (`?simulate=error`로 검증)
- 잘못된 입력: 필수(작업 목적, 대상물) 누락, 수량 형식 오류
